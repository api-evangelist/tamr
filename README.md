# Tamr (tamr)

An enterprise data management company that uses machine learning to automate the mastering, enrichment, and classification of messy data across disparate sources. Helps large organizations unify customer, supplier, and product data to power analytics and AI initiatives.

## APIs

- **Tamr Core REST API** — Programmatic access to the on-premise Tamr platform: dataset management, projects, ML training/prediction, and continuous mastering. Docs: https://docs.tamr.com/
- **Tamr Cloud API** — SaaS APIs for tenant management, data products, enrichment, and AI-driven mastering. Docs: https://docs.tamr.com/

## Tools and SDKs

- **tamr-client** (Python) — Official Python client (PyPI `tamr-unify-client`). https://github.com/Datatamer/tamr-client
- **tamr-toolbox** (Python) — High-level helper library for common Tamr workflows. https://github.com/Datatamer/tamr-toolbox
- **tamr-cloud-sdk-python** — Python SDK for Tamr Cloud. https://github.com/Datatamer/tamr-cloud-sdk-python
- **Terraform modules** — Deployment modules for AWS (EMR, RDS PostgreSQL), GCP (IAM, Bigtable, Cloud SQL, buckets), and Azure (Databricks).
